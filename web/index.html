LibrePadPS5

Use your gamepad on PS5.

Connected gamepads

Each gamepad uses its own virtual pad and console profile. Native DualSense controllers stay on their reserved profiles.

Connecting...

Plug in a USB gamepad, select Reconnect, then press Home / PS. Use a separate console user from your DualSense.

Bluetooth

Disabled at startup. Only the selected address can pair or reconnect. Unplug USB controllers first. Native DualSense isolation is not guaranteed: stop immediately if it stops working. Keep a USB data cable available.

Bluetooth disabled

Put the controller in pairing mode. Address is available from a PC's Bluetooth device details. Pairing lasts 120 seconds. Use Reconnect after releasing an already connected pad.

Need to add a gamepad, change mappings or download troubleshooting logs? Open Advanced.

Custom drivers, remapping and diagnostics. These settings are optional for recognized controllers.

Input & native controllers

Checking...

Release the virtual pad to check native controller behavior. If a DualSense cannot pair, connect it by USB and press PS.

Controller profiles

Choose a USB driver or Bluetooth mapping, then map inputs to PS5 buttons. For other USB gamepads, try the generic HID driver or define a raw report layout. Native DualSense USB devices are protected from capture.

Byte offsets include the report ID. Use -1 for absent ID, hat or axes. Custom raw buttons use absolute bit numbers, least-significant bit first. Built-in driver mappings use named PS5 inputs; source bits are ignored.

Release all virtual pads before saving. Save applies atomically; then Reconnect. Adding a device may require unplugging/replugging it. Resetting mappings does not save until you update the editor and select Save.
