Release the virtual pad to check native controller behavior. If a DualSense cannot pair, connect it by USB and press PS.

Controller profiles

Add your controller’s USB IDs and report layout, then map inputs to PS5 buttons. Supports button bits, a hat and unsigned 8-bit axes. Sony USB IDs are blocked.

Byte offsets include the report ID. Use -1 for absent ID, hat or axes. Buttons use absolute bit numbers, least-significant bit first.

Release the virtual pad before saving. Save applies atomically; then Reconnect. Adding a device may require unplugging/replugging it. Resetting mappings does not save until you update the editor and select Save.
