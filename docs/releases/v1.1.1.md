LibrePadPS5 v1.1.1 is a normal release with the USB fixes from v1.1.1-preview, plus automatic controller recovery after logout and clearer USB connection notifications.

- **8BitDo Adapter 2:** includes the preview's input-read ordering, interrupt-output and USB completion fixes. A tester on PS5 13.60 confirms Xbox Series and PS4 controllers working in PS4/PS5 games, emulators and homebrew, with [plug, pair and play without changing modes](https://github.com/arwebSE/LibrePadPS5/issues/1#issuecomment-6115150398). Manual XInput switching is now troubleshooting advice.
- **Recovery after logout:** when the last signed-in account logs out, active owned virtual controllers are re-registered automatically while physical USB/radio connections remain intact. Wait for registration to finish, then press Home/PS and choose a profile. Released controllers remain released. Failed login-list reads and transient empty lists do not trigger recovery.
- **USB protocol notifications:** connection notifications and logs show the detected protocol and USB ID, such as `XInput (2dc8:3106)`. Both adapter modes reported by the tester expose the same XInput interface, so the payload cannot reliably name the selected adapter mode or controller behind it. The notification appears when a device is claimed again, including mode changes that cause USB rediscovery.
- **Settings cleanup:** settings, logs and Xbox firmware now use `/data/LibrePadPS5`. Existing files migrate automatically, with compatibility aliases for older payloads and a shared instance lock. Stop the old payload before upgrading and keep your saved settings.

The dashboard stays included. Internal Bluetooth starts disabled and is opened only after explicit pairing; using USB does not enable it. The 8BitDo adapter handles its own pairing and does not need Microsoft's Xbox adapter firmware.

Validation: all 21 C/C++ host suites passed with AddressSanitizer and UndefinedBehaviorSanitizer, dashboard JavaScript checks passed, and combined, no-Xbox-module and standalone Xbox PS5 SDK builds passed without compiler warnings. Logout tests cover recovery and fresh device identification, Home pressed while registering, multiple players, transient/error login lists, paused/released pads, pending ownership discovery, failed removal and avoiding repeated recreation at the login screen. The USB fixes have tester hardware confirmation in the preview; the new automatic logout recovery still needs confirmation on a PS5. The original issue #1 no-notification startup report remains open.

Download `LibrePadPS5.elf`, its matching Payload Manager JSON and SHA-256 file. `LibrePadPS5-Xbox-Setup.zip` is optional for Microsoft's Xbox Wireless Adapter.
