LibrePadPS5 v0.5.2-preview adds a simple way to share troubleshooting information on GitHub. It includes the startup diagnostics and 8BitDo XInput fixes from v0.5.1-preview.

- **Advanced > Logs & support > Download diagnostic report (.txt)** saves a report with the payload version, PS5 firmware, controller state, Bluetooth status, latest USB report, saved mappings and up to 256 KiB of recent logs.
- Large logs are clearly marked as truncated. Missing logs are reported in the file; download failures return an error. Bluetooth bond keys and account-list files are excluded.
- **Open GitHub issue** opens a controller/startup issue form with the payload version and firmware prefilled. Logs are optional; review the .txt and attach it yourself. If you already have an issue, attach it in a comment there.
- Added reporting instructions in the dashboard, README and [setup guide](https://github.com/arwebSE/freepad-usb-ps5/blob/main/docs/FREEPAD.md#share-a-diagnostic-report-on-github), including FTP/loader-output fallback when the dashboard cannot start.

**Quick reporting steps:** reproduce the problem, download the report while the payload is running, review its contents, then drag the .txt into your GitHub issue/comment or use GitHub's attachment control. Include the controller/adapter model, adapter mode and ELF loader name/version. A GitHub account is required to submit. Logs may contain profile names/IDs and device addresses; remove anything you do not want to share publicly.

If the dashboard never opens, retrieve `/data/pdp-pad/pdp-pad.log` through FTP and rename the downloaded file to `.txt` before attaching, or paste relevant lines. If there is no new log, share the loader output and whether a startup notification appeared.

Validation: all seven payload host suites passed with AddressSanitizer/UndefinedBehaviorSanitizer, including complete, missing, truncated and unreadable log downloads, attachment headers/content length and exclusion of bond secrets. Dashboard tab and GitHub prefill tests passed, and the issue-form YAML was validated. Browser testing confirmed the .txt download and the support controls. The PS5 SDK v0.43 build passed. This update has not been loaded onto a live PS5; firmware 13.60 and the reported Adapter 2 setup still need tester confirmation.
