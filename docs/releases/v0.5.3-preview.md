LibrePadPS5 v0.5.3-preview follows up on the Adapter 2 logs in [issue #1](https://github.com/arwebSE/LibrePadPS5/issues/1).

- Recognizes `2dc8:3107` as the idle 8BitDo Adapter 2 receiver. It logs a waiting-for-controller message once per appearance and keeps polling for the connected gamepad identity, without claiming the idle interface or flooding the log with descriptor failures. A saved custom profile cannot override this idle-device exclusion.
- Logs the selected USB driver, interface and endpoints. Generic HID failures now distinguish a descriptor read error, a non-gamepad descriptor and a parser failure.
- Adds exact Xbox Series and DualShock 4 pairing/XInput checks and explains that a PS5 profile picker alone does not confirm USB input.
- The repository is now [arwebSE/LibrePadPS5](https://github.com/arwebSE/LibrePadPS5). Dashboard issue links, download links and Payload Manager metadata use the new name.

For Adapter 2: pair one controller and confirm its LED is solid. Hold **View + Up** on Xbox Series, or **Share + Up** on DualShock 4, for three seconds until the adapter LED blinks twice, then replug and allow the controller to reconnect. Leave payload Bluetooth disabled. Check the latest raw report while pressing buttons. If input still fails, download **Advanced > Logs & support > Download diagnostic report (.txt)**, review the file and attach it to issue #1. Logs are optional.

This update corrects idle-receiver handling and improves diagnosis; working input on the reporter's PS5 remains unconfirmed. No new input protocol was inferred from the idle descriptor. Firmware 13.60 still needs hardware confirmation.

Validation: payload host regression suites passed with AddressSanitizer and UndefinedBehaviorSanitizer, including idle-versus-connected adapter IDs and XInput reports. Dashboard JavaScript tests and the PS5 SDK v0.43 build passed. This build has not been loaded on a live PS5.

Download the ELF, matching Payload Manager JSON and SHA-256 file below. Stop the old instance before loading and keep `/data/pdp-pad/` settings. [Adapter instructions](https://github.com/arwebSE/LibrePadPS5/blob/main/docs/SETUP.md#8bitdo-usb-wireless-adapter-2).
