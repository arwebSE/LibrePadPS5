# LibrePadPS5 v1.1.4

> Version-specific release notes. For current setup and firmware requirements,
> see [setup](../SETUP.md) and [release history](README.md).

Fixes DualShock 3 USB input, [confirmed working on PS5 firmware 11.40](https://github.com/arwebSE/LibrePadPS5/issues/4#issuecomment-6228485447).

- Fixed controller initialization and input streaming.
- Improved USB recovery, preserving the assigned user when reconnection succeeds.
- Added physical-input diagnostics for troubleshooting.

Thanks to [h1z1z1h16584](https://github.com/h1z1z1h16584) for DualShock 3 USB testing.

replace the ELF and JSON together. Existing settings and Xbox firmware are kept.

Validation: PS5 SDK build and sanitized USB transport/protocol tests passed.
