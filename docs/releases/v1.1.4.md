# LibrePadPS5 v1.1.4

DualShock 3 controllers now have confirmed working USB input on PS5 firmware
11.40. This stable release includes the fixes verified in DS3 test 5 and replaces
v1.1.3 as the normal download.

## DualShock 3 USB fixes

- Correct USB initialization with checked F2/F5 feature reads and the USB
  reporting-enable request, F4 with `42 0c 00 00`.
- Independent control and USB_FS input handles, verified device identity and
  kernel-driver ownership handling for the known DS3 interface.
- Deferred output/LED configuration after input starts, with both motors off.
- Bounded transport recovery that clears held input and preserves the virtual
  controller and user assignment when reconnection succeeds.
- Physical-report, timeout and pending-read diagnostics, separate from the
  virtual-pad frame counter.

## Confirmed testing and credits

Huge thanks to [h1z1z1h16584](https://github.com/h1z1z1h16584) for patiently testing
all five builds, sharing detailed logs and helping bring DS3 USB support to the
community. [Their confirmation and diagnostic report](https://github.com/arwebSE/LibrePadPS5/issues/4#issuecomment-6228485447)
show working input with the PS5 controller overlay on firmware 11.40.

The report contains three successful sessions with 46,487, 19,502 and 15,602
physical reports, about 100 reports per second, button presses/releases and
successful user binding. No input timeouts or USB transport failures occur
during those sessions. The two completed sessions stop cleanly. One earlier F2
initialization failure is followed by a successful retry.

This confirmation covers DS3 over USB on that setup. DS3 Bluetooth and
game-specific compatibility are outside that test's coverage.

## Upgrade

Stop the running payload, then load `LibrePadPS5.elf`. For Payload Manager,
replace the ELF and matching JSON together. Existing settings and Xbox firmware
are retained. Connect the DS3, press its physical PS button and assign its
virtual pad to a separate signed-in user. [Setup](https://github.com/arwebSE/LibrePadPS5/blob/main/docs/SETUP.md#dualshock-3-usb).

The optional `LibrePadPS5-Xbox-Setup.zip` is included for new Xbox Wireless
installations; existing installations do not need to reinstall firmware.

## Release validation

- Combined stable-version ELF built with PS5 Payload SDK v0.43 and LLVM.
- USB transport and protocol suites passed with AddressSanitizer and
  UndefinedBehaviorSanitizer, including the USB enable request, continued
  changing input, timeout re-arming, independent handles, failed/short requests,
  bounded recovery, device identity protection and XInput behavior.
- Repository punctuation, include/documentation and diff checks passed.
- The DS3 controller behavior was physically confirmed in test 5; the stable
  build uses the same controller code with the normal v1.1.4 version identifier.
