LibrePadPS5 v1.1.0 preview reduces Xbox Wireless setup to one Windows helper or a dashboard file upload, and increases the shared virtual-controller capacity to four. v1.0.0 remains the stable Latest release.

## Setup changes

- **One Windows helper:** extract `LibrePadPS5-Xbox-Setup.zip`, run `setup.cmd` and enter your PS5 IP. The helper downloads Microsoft's driver package, extracts the tested 2017 firmware with Windows' built-in CAB tool, verifies its pinned SHA-256 and installs it through the dashboard. No Python, FTP or separate Xbox payload is needed.
- **Dashboard installation:** Controller > Xbox Wireless setup shows firmware and connection status. Choose an existing `.bin` file and select Install firmware. Installation saves atomically and queues an Xbox backend restart; incomplete or invalid uploads keep the previous file. Unplug/replug the adapter afterward to clear its resident firmware.
- **Four virtual slots:** slots allocate as devices connect. Each virtual player needs a separate signed-in PS5 profile. PS5 supports four signed-in users in total; reserved native profiles reduce the profiles available to virtual players. One Xbox controller per adapter remains the backend limit.
- **Simpler first setup:** leave third-party gamepads unplugged, load the main ELF and reserve native DualSense profiles in Advanced before connecting them. No manual user-ID files or FTP are needed for normal setup.
- **Repository layout:** Xbox runtime is under `src/xbox`, third-party cores under `vendor`, and build recipes, tools and reference material have dedicated directories. Active names use LibrePadPS5; old console paths and control-header aliases stay compatible.

## Try it

1. Stop the previous payload and load the attached `LibrePadPS5.elf` with its matching JSON metadata if using Payload Manager.
2. Keep `/data/pdp-pad/` and existing native-profile reservations, mappings and pause settings.
3. Reserve all native DualSense profiles in Advanced. Assign each virtual gamepad to its own signed-in profile.
4. For Xbox Wireless, run the attached setup ZIP or use the dashboard's firmware file picker. Unplug/replug the adapter and pair.

The firmware is downloaded from Microsoft by the helper and is not bundled in these assets. Already-installed firmware is retained. ## Validation and coverage

All 19 C/C++ host suites pass with ASan/UBSan, including four-slot allocation and distinct-profile binding, fourth-slot Bluetooth exclusion, binary uploads, incomplete/invalid-file preservation and queued Xbox recovery. Dashboard JavaScript tests cover upload bounds, replacement, status and error handling. The Windows helper was tested with a real Microsoft download, native extraction and hash verification against a disposable HTTP server, including rejection of a different image. It also installed successfully through the actual C dashboard running with mocked console services in a disposable container. Combined, USB/Bluetooth-only, standalone Xbox and portable builds were checked with PS5 Payload SDK v0.43.

This preview is installed and running on PS5 12.60. Its dashboard serves the exact published assets and exposes four slots. The Windows helper installed the tested firmware through the live dashboard; FTP read-back verified its SHA-256 and unchanged profile-protection settings. Xbox input with this preview and four-player game behavior still require confirmation. Existing hardware coverage remains PDP `0e6f:0184` and Xbox One model 1697 through receiver `045e:02e6` on PS5 12.60. One Xbox controller per receiver, Bluetooth hardware and the open 13.60/8BitDo reports retain the limits described in [controller coverage](https://github.com/arwebSE/LibrePadPS5/blob/main/docs/CONTROLLERS.md). The LAN dashboard has no authentication.

If you want to share results, Advanced > Logs & support downloads a diagnostic `.txt` report. Review it and attach it to your existing issue or [a new controller report](https://github.com/arwebSE/LibrePadPS5/issues/new?template=controller_problem.yml).
