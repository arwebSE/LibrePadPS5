LibrePadPS5 v1.1.3 fixes the v1.1.2 startup regression that could leave both USB detection and the dashboard unavailable.

* **Startup fixed:** the storage migration no longer requires symbolic links, which the tested PS5 `/data` filesystem rejects. This failure happened before controller and dashboard initialization.
* **Saved settings preserved:** migration copies settings and Xbox firmware to `/data/LibrePadPS5`, retains an older-version rollback snapshot, and can recover the directory move left by v1.1.2. Stop the old payload before upgrading. Keep your files; no manual folder moves are needed.
* **Clearer failures:** startup reports the failed operation, path and error number in the notification and loader output, even if the log file cannot be opened.

The dashboard, preview USB fixes, USB protocol notifications and automatic logout recovery remain included. Internal Bluetooth still starts disabled.

Verified on a PS5 running **12.60**: the published v1.1.2 startup failure, fixed dashboard startup, fresh installation, legacy settings/firmware migration, recovery after an interrupted v1.1.2 directory move, restart, rollback to v1.1.1-preview, duplicate-instance protection and diagnostic downloads. Saved profile settings and Xbox firmware were checked byte for byte against backups. All 21 C/C++ host suites passed with AddressSanitizer/UndefinedBehaviorSanitizer; dashboard checks and combined, no-Xbox-module and standalone Xbox SDK builds passed.

This is a normal release, and the project is still in early development. Physical controller input was not re-tested for this patch; automatic logout recovery and startup on 11.40/13.60 still need tester confirmation. The earlier working preview has 8BitDo Adapter 2 input confirmation on 13.60. Issues #1 and #3 remain open until their reporters can confirm the fix.

Download `LibrePadPS5.elf`, its matching Payload Manager JSON and SHA-256 file. The Xbox setup ZIP is optional; existing adapter firmware does not need reinstalling.
