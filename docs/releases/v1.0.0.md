LibrePadPS5 v1.0.0 is the new stable main release, replacing v0.3.2 as the default download. It brings the controller, dashboard and troubleshooting improvements from the v0.4 and v0.5 previews into one release.

## Changes since v0.3.2

- **Multiple controllers:** up to three independent virtual gamepads, with wired USB and one Xbox Wireless controller running together. Each pad has its own profile assignment, release/reconnect controls, input state and persistent pause setting. Native DualSense profiles can be reserved in the dashboard.
- **Xbox Wireless in the main ELF:** the xow-based module is included by default. Pairing, reassociation and radio restart improvements are integrated with the shared controller manager. Microsoft receiver firmware must be staged separately; it is not included in this download. [Xbox setup](https://github.com/arwebSE/LibrePadPS5/blob/main/docs/XBOX.md#firmware).
- **More USB drivers:** dedicated DualShock 3/4, Xbox/XInput/GIP, Switch Pro/NSO and 8BitDo handling, plus descriptor-based generic HID gamepads. XInput interface selection keeps endpoints together and prefers the matching vendor interface. Adapter 2's idle `2dc8:3107` identity is recognized and left waiting for a connected controller.
- **Controller profiles and remapping:** editable USB IDs, driver selection, custom raw layouts and named button mappings. Generic HID mappings can also customize axes and buttons.
- **Opt-in Bluetooth:** Classic and LE HID, Secure Connections, bond storage and reconnect support from the AnyPad core. Bluetooth starts disabled and uses an explicitly selected controller address; it is an alternative mode to USB/Xbox input.
- **Dashboard:** everyday connection controls and advanced configuration are separated, with per-pad input displays, native-profile reservations, keyboard-accessible tabs and improved layout/UTF-8 rendering.
- **Startup diagnostics:** versioned starting/ready/failure notifications and more precise firmware, privilege, virtual-pad and USB transport logs. The dashboard shows the running version and firmware.
- **Optional GitHub reports:** download a `.txt` diagnostic report under **Advanced > Logs & support**, review it, and attach it to an existing issue or the new issue template. Reports include controller state, mappings, latest raw USB input and up to 256 KiB of recent logs. [Reporting instructions](https://github.com/arwebSE/LibrePadPS5/blob/main/docs/SETUP.md#share-a-diagnostic-report-on-github).
- **Project identity:** the app and repository are now LibrePadPS5, with matching dashboard links and Payload Manager metadata.

## Upgrade from v0.3.2 or a preview

1. Stop the old payload before loading the new `LibrePadPS5.elf`.
2. Keep `/data/pdp-pad/` and its existing settings. The legacy directory, protected-profile files and shared instance lock remain compatible.
3. Reserve every native DualSense profile in Advanced and assign each virtual pad to a separate signed-in PS5 profile.
4. For Xbox Wireless, stage the receiver firmware as described in the Xbox guide. For 8BitDo Adapter 2, pair a controller and manually select XInput mode using the [adapter instructions](https://github.com/arwebSE/LibrePadPS5/blob/main/docs/SETUP.md#8bitdo-usb-wireless-adapter-2).

Payload Manager users should install the matching ELF and JSON below together. The SHA-256 file verifies the ELF download.

## Hardware coverage and open reports

The PDP wired controller `0e6f:0184` and Xbox One model 1697 through Microsoft receiver `045e:02e6` were verified on PS5 12.60, including simultaneous use with separate profiles. This v1.0.0 build has been verified in software and has not been loaded on a live console.

Firmware 13.60 startup and working input through the reported 8BitDo Adapter 2 setup remain unconfirmed in [issue #1](https://github.com/arwebSE/LibrePadPS5/issues/1). Bluetooth hardware, other controller models and game-specific four-player behavior remain unverified. The stable release designation does not expand the hardware-tested coverage. [Controller coverage and limits](https://github.com/arwebSE/LibrePadPS5/blob/main/docs/CONTROLLERS.md).

The dashboard is for a trusted LAN and has no authentication. Game-driven rumble, controller audio, motion forwarding and touchpad movement are not provided.

## Validation

All 14 payload/Bluetooth host suites and five Xbox Wireless host suites passed with AddressSanitizer and UndefinedBehaviorSanitizer. Dashboard JavaScript tab and GitHub reporting tests passed. The complete main ELF built with PS5 Payload SDK v0.43, and uploaded release assets were checked against local SHA-256 hashes.
