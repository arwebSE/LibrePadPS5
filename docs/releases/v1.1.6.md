# LibrePadPS5 v1.1.6

- Added dashboard translations for Japanese, Spanish, German, French, Swedish and Simplified Chinese alongside English.
- The dashboard detects supported browser languages and falls back to English. The language menu remembers your choice in that browser; it does not use the PS5 system language.
- Translated controller controls, advanced settings, setup instructions, accessibility labels and known status/error messages. Language changes preserve the selected controller and unsaved profile edits.
- Updated mobile layouts for longer translated labels. All translations are included in the offline dashboard bundle.

Downloads: `LibrePadPS5.elf`, Payload Manager metadata `LibrePadPS5.elf.json` and `LibrePadPS5.elf.sha256`.

Validation includes 47 dashboard interaction and translation tests, a production frontend build, repository checks, byte-for-byte verification of the compiled embedded dashboard assets, and all seven Xbox host regression suites with ASan/UBSan. Controller compatibility remains as documented in the [current compatibility guide](../CONTROLLERS.md); this release does not add new hardware compatibility claims.
