LibrePadPS5 v1.1.1-preview investigates the new Adapter 2 log in [issue #1](https://github.com/arwebSE/LibrePadPS5/issues/1#issuecomment-6114714250).

The reporter's v1.1.0 run reaches Ready on PS5 13.60 and selects the adapter's XInput interface (`2dc8:3106`, IN `0x81`, OUT `0x02`), but receives no input reports. This confirms startup and enumeration for that run; working controller input remains unconfirmed.

- Starts XInput input reads before the optional vendor initialization request, matching the ordering in [Linux xpad](https://github.com/torvalds/linux/blob/master/drivers/input/joystick/xpad.c).
- Sends the XInput player LED command through the selected OUT endpoint instead of HID SET_REPORT. An unsupported vendor request or LED command does not prevent input.
- Preserves input completions that arrive during an output command. USB_FS completions are device-wide, so an OUT completion must not clear a pending IN read.
- Reports USB transfer status and start/completion errors instead of silently labeling failed transfers as idle. Normal input timeouts remain idle; repeated actual transfer errors can close and rediscover the device. Error-status logs are rate limited.

The missing Xbox firmware message applies only to Microsoft's Xbox Wireless Adapter. The 8BitDo adapter does not need that firmware.
