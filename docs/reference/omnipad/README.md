# Archived OmniPad reference

This directory retains the reference-only source, obsolete exploratory tests
and TCP frame tool that previously sat in the active source/test/tool directories.
They are preserved for comparison and provenance, not compiled by LibrePadPS5.
The test snapshots refer to older layouts and helpers that are no longer part
of the application; they are not current regression tests. The TCP tool targets
the old OmniPad port and is not an input interface to LibrePadPS5.

Original source attribution remains intact. For active code, tests and build
commands, see [the development guide](../../DEVELOPMENT.md).
